### Key Technical Decisions
- Primary analysis: Cox regression + KM (not ML as primary)
- ML/DL: exploratory only due to sample size
- Endpoint: durable endocrine remission
- BED: exploratory (may have missing data)
- Center adjustment: robust sandwich SE or frailty Cox
