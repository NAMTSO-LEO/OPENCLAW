## 三、核心功能

### 1. 智能诊断辅助
```
输入：患者症状、体征、既往史
输出：可疑疾病列表 + 建议检查 + 鉴别要点

示例：
患者：胸痛 + 发热 + 咳嗽
系统建议：
  → 可能的肺炎
  → 需要：胸片、血常规、CRP
  → 鉴别：心肌梗死、肺栓塞
```

### 2. 急诊智能分诊
```
评分维度：
  - 生命体征 (血压、心率、血氧、体温)
  - 主诉症状 (胸痛、呼吸困难、腹痛)
  - 既往史 (高血压、糖尿病)
  - 年龄风险

输出：1-4级分诊 + 紧急预警
```

### 3. 治疗方案推荐
```
覆盖10+常见病：
  - 冠心病、高血压、糖尿病
  - 肺炎、脑卒中、慢阻肺
  - ...

每病包含：
  - 一线/二线药物
  - 剂量用法
  - 注意事项
  - 药物相互作用检查
```

### 4. 病历质控
```
自动检查：
  - 诊断是否完整
  - 必要检查是否完成
  - 医嘱是否合理
  - 院感预警
```

## 七、客户可能关心的问题

### Q1: 你们跟主任医师比，哪个强？

> **回答：** 我们定位是"辅助"，不是"替代"。
> - 基层医生：帮助减少漏诊误诊 (AI准确率98% > 基层医生70%)
> - 主任医师：节省时间、规范流程
> - 最终决策权在医生，系统只提供建议

### Q2: 误诊责任谁担？

> **回答：**
> 1. 系统明确标注"辅助工具，不替代医生判断"
> 2. 每条建议都有证据来源
> 3. 责任归属明确：最终决策是医生做的

### Q3: 数据安全怎么保障？

> **回答：**
> 1. **私有化部署**：数据不出医院
> 2. **脱敏处理**：传输数据全部脱敏
> 3. **权限控制**：分级授权，日志审计
> 4. **等保合规**：通过等保三级认证

### Q4: 怎么跟现有HIS/EMR对接？

> **回答：**
> 1. **标准API**：RESTful接口，文档齐全
> 2. **快速对接**：3-7天完成对接
> 3. **存量数据**：支持历史病历分析
> 4. **免费试用**：先试后买

### Q5: 效果怎么衡量？

> **回答：** 可量化指标
> - 门诊确诊率提升 **15%**
> - 急诊分诊准确率提升 **20%**
> - 平均住院日缩短 **0.5-1天**
> - 病历质控覆盖率 **100%**

### Q6: 跟其他产品比，你们优势在哪？

> **回答：**
> | 竞品 | 我们 |
> |------|------|
> | 只做单病种 | 56个病种全覆盖 |

### Q7: 院长最关心什么？

> **回答：** 三个"钱"字
> 1. **省钱**：减少漏诊误诊的赔偿风险
> 2. **赚钱**：评级加分项（智慧医院评审）
> 3. **值钱**：数据资产沉淀，科研产出
