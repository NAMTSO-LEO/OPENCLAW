## 三、短视频制作步骤

### Step 1: 下载剪映

```
手机应用商店搜索 "剪映" → 下载安装
```

### Step 2: 找素材

**方法A: 自己拍**
- 找朋友演
- 自己演
- 不用露脸也行

**方法B: 混剪**
- 用已有视频素材
- 电影/电视剧片段
- 之前下载的YouTube视频

### Step 3: 制作

**剪映操作**:
```
1. 打开剪映 → 开始创作
2. 导入视频/图片素材
3. 剪辑: 分割、删除不需要的部分
4. 添加文字: 场景说明
5. 添加音频: 我帮你生成的配音
6. 添加音乐: 选一首背景音乐
7. 导出 → 保存到相册
```
