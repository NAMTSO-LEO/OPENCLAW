##五、制作流程

###5.1 素材收集 (Day 1-2)

**来源优先级**:
```
1. 原创/授权内容 (无版权风险)
2. 公开平台下载 (YouTube、Pornhub等)
3. 付费订阅内容 (购买使用权)
```

**工具**:
| 工具 | 用途 |
|------|------|
| yt-dlp | 下载YouTube视频 |
| IDM | 高速下载器 |
| JDownloader | 批量下载 |

###5.2 筛选标准

```
素材筛选条件:
├── 画质: 720P起步, 1080P优先
├── 演员: 亚洲面孔
├── 内容: 无违规
├── 时长: 单片段30秒-3分钟
├── 质量: 清晰度、角度、光线
└── 标签匹配: 符合目标类别
```

###5.3 剪辑要点

**结构**:
```
0:00-0:05 片头(最高潮片段)
0:05-0:30 精彩片段#1
0:30-1:00 精彩片段#2
1:00-1:30 精彩片段#3
1:30-2:00 精彩片段#4
2:00-2:30 精彩片段#5
2:30-2:35 片尾(订阅提示)
```

**技巧**:
| 技巧 | 说明 |
|------|------|
| 节奏 | 随音乐节拍切换 |
| 转场 | 快速切、无缝转 |
| 高潮 | 每30秒一个高潮点 |
| 音乐 | 选择无版权电子音乐 |
| 字幕 | 添加中文字幕 |

###5.4 缩略图设计

**模板**:
```
┌─────────────────────┐
│  [最大亮点画面]      │
│                     │
│  标题文字           │
│  #标签              │
└─────────────────────┘
```

**要点**:
- 使用最精彩的画面
- 文字简洁有力
- 高对比度配色
- 16:9 比例
