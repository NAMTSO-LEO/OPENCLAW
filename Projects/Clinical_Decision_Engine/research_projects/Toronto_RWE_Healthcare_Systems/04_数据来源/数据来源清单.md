# 多伦多地区RWE数据来源

## 一、主要数据来源

### 1.1 省级数据库

| 数据库 | 描述 | 申请方式 |
|--------|------|----------|
| ICES Data | 安省健康数据库 | 研究申请 |
| CIHI | 加拿大健康信息研究院 | 机构合作 |
| Ontario Health Data | 省级健康数据 | 审批后使用 |
| Cancer Care Ontario | 肿瘤登记数据 | 研究合作 |

### 1.2 医院数据

| 来源 | 内容 | 可及性 |
|------|------|----------|
| EMR数据 | 临床诊疗记录 | 合作研究 |
| 医院数据仓库 | 管理/临床数据 | 伦理审批 |
| PACS影像 | 影像数据 | 研究协议 |

### 1.3 家庭医生数据

| 来源 | 内容 | 可及性 |
|------|------|----------|
| EMR (OSCAR/Accuro) | 门诊记录 | 需合作 |
| 省级处方数据库 | 药物处方 | 有限获取 |
| 免疫数据库 | 疫苗接种 | 公共卫生 |

### 1.4 其他数据

| 来源 | 内容 |
|------|------|
| Death Database | 死亡数据 |
| ORGD | 器官移植登记 |
| NACRS | 门急诊数据 |
| DAD | 住院数据 |

## 三、数据质量评估

### 3.1 完整性
- 缺失数据比例
- 数据覆盖率

### 3.2 准确性
- 验证诊断准确性
- 实验室数据校准

### 3.3 一致性
- 跨系统变量定义
- 编码一致性

### 3.4 时效性
- 数据更新频率
- 研究时间窗口

## 四、数据申请流程

### 4.1 机构层面
1. 确定研究问题
2. 伦理审批
3. 数据使用协议
4. 数据提取

### 4.2 省级数据库（ICES为例）
1. 提交研究方案
2. 伦理审批
3. 数据访问申请
4. 数据提取和分析
5. 结果验证
