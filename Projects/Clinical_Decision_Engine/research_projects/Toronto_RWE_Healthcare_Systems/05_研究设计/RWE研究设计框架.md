## 二、研究设计框架

### 2.1 研究问题

| PICO框架 | 内容 |
|----------|------|
| P (Population) | 研究人群 |
| I (Intervention) | 干预/暴露 |
| C (Comparison) | 对照 |
| O (Outcome) | 结局 |

### 2.2 研究人群

#### 家庭医生系统
- 慢病患者
- 签约居民

#### 医院系统
- 住院患者
- 急诊患者
- 门诊患者

#### 跨系统
- 转诊患者
- 护理连续性研究

## 三、研究设计示例

### 3.1 家庭医生系统RWE

**示例1：糖尿病管理效果**
```
研究问题：家庭医生管理的糖尿病患者HbA1c控制率及影响因素
数据来源：家庭医生EMR数据
人群：2型糖尿病患者
暴露：不同管理模式的家庭医生诊所
结局：HbA1c控制达标率
```

**示例2：预防保健覆盖率**
```
研究问题：不同社区老年人疫苗接种率比较
数据来源：EMR+公共卫生数据库
人群：65岁以上老年人
暴露：居住社区类型
结局：流感/肺炎疫苗接种率
```

### 3.2 医院系统RWE

**示例1：急诊等待时间分析**
```
研究问题：多伦多医院急诊等待时间及影响因素
数据来源：医院EMR+NACRS
人群：急诊患者
暴露：医院特征
结局：等待时间、入院率
```

**示例2：手术预后研究**
```
研究问题：手术后30天死亡率及影响因素
数据来源：医院数据仓库+DAD
人群：手术患者
暴露：手术类型
结局：30天死亡率、并发症
```

### 3.3 跨系统RWE

**示例1：转诊效率研究**
```
研究问题：家庭医生转诊到大医院的效率分析
数据来源：家庭医生EMR+医院EMR
人群：转诊患者
暴露：转诊模式
结局：转诊时间、接诊质量
```

**示例2：护理连续性**
```
研究问题：慢病患者从医院到社区的护理连续性
数据来源：医院+家庭医生数据
人群：出院后慢病患者
暴露：不同随访模式
结局：再入院率、结局
```
