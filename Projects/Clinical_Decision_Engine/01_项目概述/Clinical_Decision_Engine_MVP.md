# 临床决策引擎（Clinical Decision Engine）
## 智能临床决策支持系统

---

## 一、项目概述

### 1.1 系统定位

**一句话定义**：
> 患者信息 → AI + 指南 + 证据 → 诊疗建议

**核心价值**：
- 辅助临床决策，不是替代医生
- 基于循证医学的诊疗建议
- 连接指南、证据与临床实践

### 1.2 与Evidence Engine的关系

| 系统 | 定位 | 用户 | 场景 |
|------|------|------|------|
| Evidence Engine | 数据分析工具 | 统计师、研究者 | 回顾性研究 |
| Clinical Decision Engine | 临床决策支持 | 医生 | 前线诊疗 |

**可以结合**：
- Evidence Engine 提供 RWE 证据
- Clinical Decision Engine 提供临床建议
- 两者共用底层数据分析能力

## 二、系统目标

### 2.1 MVP目标

| 阶段 | 目标 |
|------|------|
| 输入 | 患者基本信息、症状、检查结果 |
| 处理 | 规则引擎 + 风险评分 + 简单ML |
| 输出 | 诊断建议 + 检查建议 + 治疗方案 + 证据来源 |

### 2.2 典型场景

**场景1：胸痛患者**
```
输入：65岁男，胸痛，Troponin↑，ECG ST改变
输出：
- 诊断：NSTEMI（85%）
- 推荐检查：冠脉造影
- 治疗：阿司匹林+他汀+β阻滞剂
- 证据：ESC 2023 guideline
```

**场景2：房颤抗凝**
```
输入：70岁男，房颤，CHA2DS2-VASc=3
输出：
- 评分：CHA2DS2-VASc=3，高血栓风险
- 推荐：口服抗凝
- 药物：DOAC优先
- 证据：ACC/AHA/ESC 2020
```

## 三、核心功能模块

### 3.1 患者数据输入

| 模块 | 字段 |
|------|------|
| 基本信息 | 年龄、性别、体重、身高 |
| 主诉 | 症状、持续时间 |
| 生命体征 | 血压、心率、体温 |
| 实验室 | 血常规、生化、凝血 |
| 影像 | ECG、CXR、CT |
| 既往史 | 病史、手术史 |
| 用药史 | 当前用药、过敏史 |

### 3.2 疾病概率评估

**评分系统**：
| 评分 | 用途 |
|------|------|
| CHA2DS2-VASc | 房颤血栓风险 |
| HAS-BLED | 抗凝出血风险 |
| Wells Score | 肺栓塞可能性 |
| GRACE Score | ACS死亡风险 |
| CHA2DS2-VASc | 卒中风险 |

### 3.3 临床路径推荐

**规则引擎逻辑**：
```
IF 胸痛 AND Troponin↑ AND ECG改变
THEN ACS → 冠脉造影路径

IF 胸痛 AND Troponin正常 AND ECG正常
THEN 排除ACS → 门诊随访路径
```

### 3.4 治疗方案推荐

**输出格式**：
| 项目 | 内容 |
|------|------|
| 药物 | 药品名+剂量 |
| 证据等级 | A/B/C级 |
| 指南来源 | ESC/ACC/AHA |
| 注意事项 | 禁忌、监测 |

### 5.1 规则系统

```python
# 胸痛规则示例
rules = {
    "chest_pain": {
        "condition": "symptom == 'chest_pain'",
        "checks": [
            {"field": "troponin", "op": ">", "value": 0.04, "conclusion": "ACS"},
            {"field": "ecg", "op": "==", "value": "ST_change", "conclusion": "ACS"}
        ],
        "pathway": "acs_pathway"
    }
}
```
