| Day 18 | Wells评分 | 肺栓塞风险 |

**评分实现**：
```python
def cha2ds2_vasc(age, gender, hf, hypertension, stroke, vascular, age65):
    """CHA2DS2-VASc评分"""
    score = 0
    if age >= 75: score += 2
    elif age >= 65: score += 1
    if gender == "female": score += 1
    if hf: score += 1
    if hypertension: score += 1
    if stroke: score += 2
    if vascular: score += 1
    return score
```

**里程碑**：✅ 评分系统完成
