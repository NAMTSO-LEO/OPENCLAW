## 四、API设计

### 4.1 核心API

| API | 方法 | 功能 |
|-----|------|------|
| /api/patient | POST | 提交患者数据 |
| /api/diagnose | POST | 诊断推荐 |
| /api/treatment | POST | 治疗推荐 |
| /api/score | GET | 计算评分 |
| /api/evidence | GET | 查询证据 |
| /api/guideline | GET | 获取指南 |

### 4.2 请求/响应示例

**诊断请求**：
```json
POST /api/diagnose
{
    "age": 65,
    "gender": "male",
    "symptoms": ["chest_pain"],
    "vitals": {"bp": "150/90", "hr": 90},
    "labs": {"troponin": 0.5},
    "ecg": "ST_change"
}
```

**诊断响应**：
```json
{
    "diagnoses": [
        {"disease": "NSTEMI", "probability": 0.85, "level": "high"},
        {"disease": "UA", "probability": 0.10, "level": "medium"}
    ],
    "recommended_tests": ["冠脉造影", "心脏超声"],
    "treatments": [
        {"drug": "阿司匹林", "dose": "300mg", "evidence": "A", "guideline": "ESC 2023"}
    ],
    "references": ["ESC 2023 NSTEMI指南", "NEJM FRISC II"]
}
```

## 六、技术选型理由

### 6.1 为什么用Streamlit

| 优势 | 说明 |
|------|------|
| 快速开发 | 几天内完成MVP |
| 无需前端 | Python直接写界面 |
| 交互性好 | 内置组件丰富 |
| 易于部署 | Docker一键部署 |

### 6.2 为什么用Python

| 优势 | 说明 |
|------|------|
| 数据科学生态 | Pandas, Scikit-learn |
| 医疗库 | PyMed, FHIR |
| 机器学习 | TensorFlow, PyTorch |
| 规则引擎 | DROOLS, CLIPS |

### 6.3 数据存储

| 存储 | 用途 |
|------|------|
| JSON | 规则库、配置 |
| SQLite | 患者数据（本地） |
| PostgreSQL | 知识库（生产） |
