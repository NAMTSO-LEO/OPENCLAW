## 10 Most Common Reasons for Rejection (And How to Avoid Them)

| # | Reason | How to Avoid |
|---|--------|--------------|
| 1 | **Generic retrospective study** | Emphasize: multicenter + advanced methods + causal inference |
| 2 | **Selection bias in treatment comparison** | Use overlap weighting + clarify as hypothesis-generating |
| 3 | **ML as gimmick** | Show ML didn't outperform; emphasize interpretability |
| 4 | **Inconsistent outcome definitions** | Clarify remission criteria + sensitivity analyses |
| 5 | **Multicenter not leveraged** | Use IECV + show consistent performance |
| 6 | **Follow-up insufficient** | Acknowledge + emphasize ongoing data collection |
| 7 | **Figures too complex** | Main paper: 5-6 figures; put complex in supplement |
| 8 | **Statistical methods overwhelming** | Explain clinical rationale for each method |
| 9 | **No external validation** | Use IECV + plan prospective validation |
| 10 | **Clinical relevance unclear** | End with clinical take-home message |

## Final Manuscript Checklist

### Title & Abstract
- [ ] Title is concise and reflects key finding
- [ ] Abstract word count within journal limit
- [ ] Abstract includes: background, methods, results, conclusions
- [ ] Keywords match journal requirements

### Introduction
- [ ] Clinical problem clearly stated
- [ ] Gap in literature identified
- [ ] Study objective clearly defined
- [ ] Not too long (aim for 2-3 paragraphs)

### Methods
- [ ] Study design clearly stated (multicenter retrospective)
- [ ] Setting and population described
- [ ] Inclusion/exclusion criteria explicit
- [ ] Outcome definitions clear (especially remission)
- [ ] Statistical methods described with enough detail
- [ ] Propensity methods explained
- [ ] Validation approach described

### Results
- [ ] Patient flow diagram (Figure 1)
- [ ] Baseline table with all key variables
- [ ] Outcome results with confidence intervals
- [ ] Predictors clearly presented
- [ ] Model performance metrics included
- [ ] Figures are clear and not overloaded

### Discussion
- [ ] Principal findings summarized first
- [ ] Comparison with prior literature
- [ ] Clinical implications clear
- [ ] Strengths acknowledged
- [ ] Limitations addressed honestly
- [ ] Not defensive about limitations
- [ ] Conclusions don't overclaim

### References
- [ ] All citations present
- [ ] Style matches journal (Vancouver/Harvard)
- [ ] Recent references included
- [ ] Key prior work cited

### Supplements
- [ ] Variable definitions table
- [ ] Missing data summary
- [ ] Sensitivity analyses
- [ ] Additional figures/tables as needed

## Technical Checklist

### Data Standards
- [ ] SDTM/ADaM specifications complete
- [ ] Variable naming consistent
- [ ] Controlled terminology used where applicable

### Statistical Code
- [ ] Code available upon request (or in supplement)
- [ ] Random seed set for reproducibility
- [ ] Software version specified (SAS, R versions)

### Figures
- [ ] Resolution adequate (300 DPI minimum)
- [ ] Fonts readable (8-10 pt minimum)
- [ ] Axes labeled clearly
- [ ] Legends complete
- [ ] Statistical tests noted

### Tables
- [ ] Headers clear
- [ ] Footnotes complete
- [ ] P-values formatted correctly
- [ ] Confidence intervals included

## Post-Submission Reminders

### If Revisions Requested
- [ ] Respond to ALL comments
- [ ] Use point-by-point format
- [ ] Don't get defensive
- [ ] Make changes clearly marked
- [ ] Thank reviewers appropriately
- [ ] Set realistic timeline

### If Rejected
- [ ] Don't take it personally
- [ ] Extract useful feedback
- [ ] Consider next journal
- [ ] Revise based on comments

---

## Final Sanity Check

Ask yourself:

1. **Can a reader understand the main finding in 30 seconds?** → Review abstract
2. **Is the clinical relevance obvious?** → Review discussion conclusion
3. **Are the methods reproducible?** → Review methods section
4. **Are the statistics appropriate?** → Review with statistician
5. **Would I accept this paper if I were a reviewer?** → Self-assess honestly
