# Evidence Engine MVP 实施方案

## 一、项目目标

在 **3个月内** 开发一个可用的医疗证据分析MVP，实现：
- 核心统计分析功能（描述性、t检验、卡方、回归、生存分析）
- Web界面操作
- 本地数据处理（保证隐私）

---

## 二、技术架构

### 2.1 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户层 (Web界面)                      │
│                   Streamlit / Gradio                    │
└─────────────────────────────────────────────────────────┘
                           │
┌─────────────────────────────────────────────────────────┐
│                   业务逻辑层 (Python)                    │
│    统计分析 │ 机器学习 │ 生存分析 │ 倾向评分          │
└─────────────────────────────────────────────────────────┘
                           │
┌─────────────────────────────────────────────────────────┐
│                      数据层                              │
│          CSV/Excel │ SQL │ FHIR │ API                  │
└─────────────────────────────────────────────────────────┘
```

### 2.2 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 前端 | Streamlit | Web界面 |
| 后端 | Python 3.9+ | 核心逻辑 |
| 统计 | SciPy, Statsmodels | 统计分析 |
| ML | Scikit-learn | 机器学习 |
| 生存 | Lifelines | 生存分析 |
| 数据 | Pandas, NumPy | 数据处理 |
| 部署 | Docker | 容器化 |

### 2.3 部署架构

- **开发阶段**：本地运行（Streamlit）
- **测试阶段**：局域网访问
- **上线阶段**：Docker + 云服务器
