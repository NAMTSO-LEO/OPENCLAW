# 丽珠医药市场与需求分析

## 一、丽珠医药公司概况

丽珠医药集团（Livzon Pharmaceutical Group）是中国领先的综合性制药企业之一，总部位于广东珠海。

### 基本情况

| 项目 | 信息 |
|------|------|
| 成立时间 | 1985年 |
| 总部 | 珠海 |
| 上市情况 | A股 + H股上市 |
| 员工 | 9000+ |
| 研发投入 | 每年约10亿元 |

### 业务覆盖

- 化学药
- 生物药
- 原料药
- 诊断试剂

丽珠在中国医药企业中属于 **研发驱动型企业**。

---

## 二、丽珠医药业务结构

### 主要业务板块

| 板块 | 内容 |
|------|------|
| 制剂药物 | 小分子创新药 |
| 生物药 | 单抗、生物制品 |

| 诊断产品 | 体外诊断 |

**核心收入来源**：化学药制剂和特色专科药

## 九、项目价值

### 1. 提高研发效率

AI可以显著减少：
- Lead发现时间：2-4年 → 6-12个月
- 虚拟筛选时间：数月 → 数周

### 2. 降低研发成本

AI可以减少：
- 动物实验次数
- 失败项目数量
- 临床试验成本

**预计降低成本**：20-40%

### 3. 提升创新能力

AI平台可以帮助丽珠：
- 加速创新药研发
- 提升技术能力
- 增强核心竞争力
