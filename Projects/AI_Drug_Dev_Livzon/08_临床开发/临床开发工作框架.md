# 临床开发工作框架

## 角色定位

**Clinical Development / Clinical Scientist / Translational Lead**

核心任务：把医学问题 → 可执行的临床试验方案

---

## 三个阶段

| 阶段 | 核心工作 |
|------|----------|
| 前期设计 | Trial Strategy, Feasibility |
| 方案开发 | Protocol Development |
| 中期策略 | Execution Optimization |

---

## 一、前期阶段：Clinical Design / Feasibility

### 1.1 明确研究问题（PICO Framework）

| 元素 | 内容 | 示例 |
|------|------|------|
| P | Patient population | metastatic NSCLC |
| I | Intervention | Drug A |
| C | Comparator | standard chemotherapy |
| O | Outcome | overall survival |

### 1.2 目标适应症和患者人群

需要确定：
- disease stage：stage III vs stage IV
- line of therapy：1st line vs 2nd line
- biomarker：PD-L1 positive

### 1.3 现有证据（Evidence Landscape）

数据来源：
- PubMed
- ClinicalTrials.gov
- Guideline（NCCN / ESMO）

梳理内容：
- 标准治疗（SoC）
- 已发表 trials
- Ongoing trials
- Unmet medical need

### 1.4 可行性评估（Feasibility）

| 评估项 | 内容 |
|--------|------|
| patient pool | 患者池大小 |
| site capability | 中心能力 |
| recruitment rate | 招募速率 |

示例：
```
China: 120 sites
Expected enrollment: 3 patients/site/month
```

## 二、临床试验方案：Protocol Development

### 2.1 研究设计（Study Design）

| 设计类型 | 说明 |
|----------|------|
| RCT | 随机对照试验 |
| Single-arm | 单臂试验 |
| Adaptive | 适应性试验 |
| Externally controlled | 外部对照 |

示例：Phase II, open-label, single-arm

### 2.2 主要终点（Primary Endpoint）

要求：
- clinically meaningful
- statistically measurable

Oncology常用终点：
| 终点 | 说明 |
|------|------|
| OS | Overall survival 总生存 |
| PFS | Progression free survival 无进展生存 |
| ORR | Overall response rate 客观缓解率 |

### 2.3 样本量（Sample Size）

统计团队计算，关键参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| alpha | 显著性水平 | 0.05 |
| power | 检验效能 | 80% |
| HR | 风险比 | 0.7 |
| effect size | 效应量 | - |

### 2.4 入排标准（Eligibility Criteria）

平衡：
- internal validity（内部效度）
- vs
- generalizability（可推广性）

示例：

**入组**：
- age 18-75
- ECOG 0-1
- confirmed diagnosis

**排除**：
- severe comorbidity
- prior therapy
- organ dysfunction

### 2.5 随访与评估

| 评估项 | 频率 |
|--------|------|
| tumor assessment | every 8 weeks |
| safety monitoring | 持续 |
| AE reporting | 持续 |

---

## 三、中期阶段：Trial Execution Strategy

### 3.1 招募策略

监控指标：
- enrollment rate：入组速率
- screen failure：筛选失败率
- dropout：脱落率

入组慢时的优化：
- add sites：增加中心
- modify criteria：调整标准
- improve screening：改进筛选

### 3.2 数据质量

与CRO DM团队合作：

监控：
- data completeness
- protocol deviation
- site performance

### 3.3 中期分析（Interim Analysis）

用途：
- futility：无效性
- efficacy：有效性
- sample size adjustment：样本量调整

### 4.2 招募预测

- site enrollment rate

### 4.3 Endpoint Extraction

NLP → disease progression

### 4.4 Synthetic Control

使用RWD + ML：
- external control arm
- 减少trial样本量
