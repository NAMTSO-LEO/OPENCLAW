# 丽珠AI药物研发平台 - 关键摘要

---

## 一、项目定位

为珠海丽珠医药集团建设**AI辅助药物研发平台**，提升创新药研发效率，降低研发成本，建立数字化研发体系。

---

## 二、市场背景

丽珠医药集团核心治疗领域：
- 消化系统
- 生殖健康
- 精神类疾病
- 生物制药

AI技术可大幅缩短药物发现周期、降低成本，是医药行业数字化转型核心方向。

---

## 三、技术架构

### 六层技术架构

| 层级 | 说明 |
|------|------|
| 数据层 | 药物研发数据整合 |
| 模型层 | AI模型训练与推理 |
| 应用层 | 药物研发各环节应用 |
| 服务层 | API与业务服务 |
| 接口层 | 系统集成 |
| 用户层 | 交互界面 |

### 六大AI模型体系

| 模型 | 功能 |
|------|------|
| 靶点发现模型 | GNN + 知识图谱识别潜在靶点 |
| 分子生成模型 | Diffusion + RL生成新分子 |
| 蛋白结构模型 | AlphaFold预测蛋白构象 |
| ADMET预测模型 | 多任务深度学习预测吸收、分布、代谢、排泄、毒性 |
| 抗体设计模型 | Protein LLM设计抗体 |
| 临床分析模型 | 因果推断分析临床数据 |
