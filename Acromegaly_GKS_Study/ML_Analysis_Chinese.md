# 机器学习与深度学习建模分析

## 中文版

除传统统计学分析外，本研究拟建立一个多模态预测框架，用于预测以下结局：

1. **持久性内分泌缓解**
2. **内分泌缓解时间**
3. **生化复发**
4. **新发垂体功能减退**
5. **补救治疗需求**

候选预测变量将包括人口学特征、内分泌指标、手术信息、影像学特征以及放射外科剂量学参数。

---

## 模型层级

### 主模型（传统统计）

传统模型（如**惩罚logistic回归、惩罚Cox回归**）将作为**主要、可解释性更强的基础模型**。

- Cox比例风险模型
- Logistic回归
- LASSO/Elastic Net

### 次级模型（机器学习）

将进一步探索机器学习方法，以捕捉非线性关系及高阶交互作用：

| 算法 | 适用场景 |
|------|----------|
| 随机森林 (Random Forest) | 二分类结局 |
| 梯度提升树 (Gradient Boosting) | 二分类/生存结局 |
| XGBoost | 二分类/生存结局 |
| 支持向量机 (SVM) | 二分类结局 |
| 随机生存森林 | 生存结局 |

### 探索性模型（深度学习）

若样本量、事件数及数据完整性允许：

- **DeepSurv** - 深度学习生存模型
- **DeepHit** - 深度学习时间-事件模型

---

## 多模态探索

对于具备高质量、标准化MRI及放疗计划数据的中心：

> 对于具备高质量、标准化MRI及放疗计划数据的中心，可进一步开展探索性多模态建模，将临床变量、MRI衍生特征及剂量学参数进行融合分析。

对于影像质量足够统一的亚组：

> 对于影像质量足够统一的亚组，可考虑开展radiomics或卷积神经网络分析，以评估影像特征是否能够提升对缓解及毒性的预测能力。

---

## 数据预处理

建模流程将包括：

| 步骤 | 方法 |
|------|------|
| 缺失值处理 | 多重插补或模型特定方法 |
| 变量标准化 | 标准化/归一化 |
| 跨中心一致化 | 固定效应/随机效应/分层 |
| 连续变量转换 | Winsorization或变换（GH、IGF-1） |

> 为降低过拟合风险，模型复杂度将依据有效样本量及结局事件数加以控制。

---

## 验证策略

模型验证将优先采用：

| 方法 | 说明 |
|------|------|
| 重复交叉验证 | Repeated K-fold |
| Bootstrap乐观校正 | Bootstrap optimism correction |
| Internal-external validation | 基于多中心设计，Leave-one-center-out |

---

## 模型性能评价

### 二分类结局

| 指标 | 说明 |
|------|------|
| 区分度 | AUC / C-statistic |
| 校准度 | Calibration slope, Brier score |
| 临床效用 | Decision curve analysis |
| 重分类 | NRI（模型比较） |

### 生存结局

| 指标 | 说明 |
|------|------|
| 区分度 | Harrell's C-index, time-dependent AUC |
| 校准度 | Integrated Brier score, 3/5/10年校准 |
| 临床效用 | Decision curve analysis |

---

## 模型可解释性

> 为提高临床可解释性，将进一步采用变量重要性排序、**SHAP值分析**及部分依赖图解释关键预测因子的作用方向与贡献大小。

### 关键预测变量（SHAP分析）

- IGF-1指数
- Knosp分级
- 肿瘤体积
- 手术到GKS间隔
- BED剂量
- 药物暂停状态

---

## 动态预测模型

> 若纵向随访数据充分，还可采用**landmark analysis**或**joint modeling**构建动态预测模型，实时更新个体化缓解概率。

这特别适合：
- 逐渐发生的缓解
- 动态IGF-1变化
- 长期随访
- 非线性变化模式

---

## 模型转化

> 最终模型若性能及外部可推广性良好，可进一步转化为**列线图（nomogram）**、**在线风险计算器**或**临床分层工具**。

---

## 样本量约束

> **机器学习与深度学习分析将被视为探索性分析，仅在样本量、事件数和数据完整性足以支持稳健的模型训练和验证时才会开展。为降低过拟合风险，模型复杂度将依据有效样本量和结局事件数进行控制。**

---

## 结局建模形式

| 结局 | 建模形式 |
|------|----------|
| 持久性缓解 | 时间-事件 (Time-to-event) |
| 缓解时间 | 时间-事件 (Cox) |
| 复发 | 时间-事件 (Cox) |
| 新发垂体功能减退 | 二分类 / 时间-事件 |
| 补救治疗需求 | 二分类 (Logistic) |

---

## 关键预测变量候选表

| 类别 | 变量 |
|------|------|
| 人口学 | 年龄、性别 |
| 内分泌 | IGF-1指数、基线GH、OGTT谷值GH |
| 肿瘤 | 肿瘤体积、Knosp分级 |
| 手术 | 手术到GKS间隔、既往手术次数 |
| 药物 | 围手术期药物暂停 |
| 放疗 | Margin剂量、最大剂量、等剂量线、视神经剂量、BED、覆盖率 |
| 策略 | 全垂体 vs 靶向方案 |

---

## 总结

本研究采用**临床可解释的统计建模框架作为主要分析方法**，机器学习模型作为预测性能增强工具，深度学习仅限于探索性分析。

此方案确保：
- ✅ IRB兼容性
- ✅ 审稿人接受度
- ✅ 符合临床期刊标准
- ✅ 利用现代AI方法增强预测能力
