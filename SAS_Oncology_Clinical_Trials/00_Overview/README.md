# SAS Oncology Clinical Trials Workflow

## Project Overview
This folder contains the complete workflow and documentation for traditional oncology clinical trial statistical programming using SAS.

## Folder Structure
- `00_Overview` - Project summary and workflow overview
- `01_Study_Protocol` - Study protocol and amendments
- `02_SAP_Statistical_Analysis_Plan` - SAP and analysis specifications
- `03_ADaM_Datasets` - ADaM dataset specifications and programs
- `04_TFLs_Tables_Figures_Listings` - TFL specifications and outputs
- `05_Programming_Code` - SAS programs and macros
- `06_QA_QC` - Quality assurance and QC documentation
- `07_Regulatory_Submission` - Regulatory submission packages
- `08_Reference_Documentation` - CDISC, FDA, ICH guidelines
- `09_Training_Notes` - Programming notes and learnings
- `10_Templates` - Reusable templates and macros

## Key Workflow Steps
1. Protocol review and SAP development
2. ADaM dataset specifications and creation
3. TFL specifications and programming
4. QC and quality assurance
5. Audit trail and documentation
6. Regulatory submission preparation
