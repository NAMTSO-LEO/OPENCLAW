# ADaM Dataset Specifications

## Common ADaM Datasets in Oncology Trials

### Subject-Level Analysis Dataset (ADSL)
- Subject identifier
- Treatment arm
- Age, Sex, Race
- Baseline characteristics
- Study disposition
- Treatment exposure

### Adverse Events Dataset (ADAE)
- Subject identifier
- Preferred Term (PT)
- System Organ Class (SOC)
- Severity/Grade
- Seriousness
- Relationship to study drug
- Outcome

### Efficacy Analysis Dataset (ADEFF)
- Endpoint variables
- Response criteria
- Tumor measurements
- PFS, OS, ORR

### Laboratory Dataset (ADLB)
- Lab test results
- Baseline values
- Change from baseline
- Grade/Normal ranges

## Key Variables
- STUDYID
- SUBJID
- ARMCD / ARM
- SAFFL (Safety Flag)
- TRTP / TRTPN
- PARAM / PARAMCD
- AVAL / BASE / CHG / PCHG
- AVALC
