# QC Checklist for Oncology Clinical Trial Programming

## Pre-Programming QC
- [ ] Review protocol and SAP
- [ ] Verify analysis dataset specifications
- [ ] Confirm TFL shells/ Mockups

## Dataset QC
- [ ] Check required variables present
- [ ] Verify variable formats and lengths
- [ ] Check for missing values
- [ ] Validate derivations against specifications
- [ ] Run consistency checks

## Output QC
- [ ] Compare to TFL shells
- [ ] Verify titles and footnotes
- [ ] Check page breaks
- [ ] Validate N counts match
- [ ] Cross-check with source data

## Program QC
- [ ] Review log for errors/warnings
- [ ] Check for hardcoded values
- [ ] Verify reproducibility
- [ ] Document changes

## Independent QC
- [ ] Second programmer review
- [ ] Blind review of outputs
- [ ] QC documented in QC log
