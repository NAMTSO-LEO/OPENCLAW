# 项目提案
## 肿瘤免疫治疗真实世界因果证据与AI融合平台构建
——以R/R DLBCL中PD-1疗效及irAE时间依赖影响为例

---

## 一、项目背景与意义

免疫治疗在肿瘤领域迅速发展，但其真实世界应用面临显著挑战。与RCT相比，真实世界患者具有更高的异质性，治疗路径复杂，导致传统统计方法难以提供可靠的因果证据。

尤其在R/R DLBCL中：
- 治疗选择偏倚显著
- irAE具有时间依赖性
- 非结构化数据利用不足

**导致**：数据丰富，但证据不足；分析存在，但难以用于决策与监管。

本项目旨在构建一个融合因果推断与人工智能技术的真实世界证据平台，实现从数据到证据的高效转化。

---

## 二、核心科学问题

本项目围绕三个递进问题展开：

1. **PD-1治疗是否在真实世界中因果改善生存？**
   - 解决选择偏倚问题

2. **irAE发生是否影响患者生存？**
   - 解决时间依赖与immortal time bias问题

3. **irAE是否作为PD-1治疗获益的生物标志物？**
   - 探索精准免疫治疗机制

---

## 三、技术路线与方法体系

本项目构建四层技术体系：

### 1. 数据层
- 医院真实世界数据（EMR、随访）
- 非结构化文本（病历、AE记录）

### 2. 因果分析层
- Target Trial Emulation
- Propensity Score + Stabilized IPTW
- Love Plot / ESS / overlap诊断

### 3. 时间依赖建模层
- start-stop数据结构
- time-dependent Cox模型
- 避免immortal time bias

### 4. AI增强层
- NLP抽取关键变量（irAE时间等）
- 风险预测模型
- 自动生成报告（CSR/注册材料）
