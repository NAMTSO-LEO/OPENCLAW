## 各层详细说明

### 1. 数据来源层

| 数据类型 | 内容 |
|----------|------|
| EMR | 电子病历结构化数据 |
| 病历文本 | 出入院记录、查房记录 |
| 检验数据 | 血常规、生化、肿瘤标志物 |
| 影像数据 | CT/MRI/PET-CT |
| 病理数据 | 免疫组化、基因检测 |
| 用药记录 | 化疗、PD-1、靶向药 |
| 随访数据 | OS、PFS、TTNT |

---

### 2. 数据治理与标准化层

| 任务 | 说明 |
|------|------|
| 数据清洗 | 重复、异常值处理 |
| 缺失处理 | 多重插补、敏感性分析 |
| 时间对齐 | 治疗时间线、随访时间 |
| 特征构建 | PS、协变量、亚组标记 |
| CDM映射 | OMOP/PCORnet标准化 |

---

### 3. AI与深度学习增强层

#### NLP/LLM模块

| 功能 | 用途 |
|------|------|
| irAE事件抽取 | 从文本识别不良事件 |
| 发病时间识别 | irAE开始时间 |
| 疗效终点抽取 | OS/PFS/ORR自动识别 |
| 病历摘要 | 自动生成研究摘要 |
| 报告生成 | CSR/注册报告自动撰写 |

#### 深度学习模块

| 模型 | 应用 |
|------|------|
| Transformer/BERT | 文本向量化 |
| 多模态融合 | 文本+检验+影像联合 |
| 表型表示 | 患者嵌入向量 |
| 风险预测 | irAE发生风险 |
| 治疗响应预测 | 哪些患者获益最大 |

---

### 4. 因果推断核心引擎

| 方法 | 用途 |
|------|------|
| Target Trial Emulation | 模拟RCT设计 |
| IPTW | 逆概率加权 |
| PS | 倾向评分匹配/加权 |
| MSM | 边际结构模型 |
| Time-dependent Cox | irAE时间依赖分析 |
| Doubly Robust | 双重稳健估计 |
| Sensitivity | 未测混杂敏感性分析 |

---

### 5. 分析模块层

| 模块 | 功能 |
|------|------|
| 疗效模块 | PD-1 vs non-PD-1, OS/PFS/ORR |
| 安全性模块 | irAE发生率、时间依赖影响 |
| 分层模块 | ECOG/LDH/线别/refractory |
| 治疗策略 | 早用vs晚用/联合vs序贯 |
| 外部对照 | External Control Arm |

---

### 6. 证据输出与解释层

| 输出 | 说明 |
|------|------|
| HR/OR | 效应量及置信区间 |
| KM/CIF | 生存曲线 |
| Love Plot | 协变量平衡可视化 |
| ESS | 有效样本量 |
| 校准曲线 | 模型校准度 |
| SHAP | 模型解释 |
| 亚组证据 | 各亚组疗效 |
| 自动报告 | JSON/Word报告 |

---

### 7. 转化应用层

| 场景 | 价值 |
|------|------|
| 临床决策 | 精准治疗推荐 |
| 论文发表 | 高质量RWE论文 |
| 基金申请 | 创新方法学支撑 |
| 注册申报 | NMPA/FDA补充证据 |
| Label Extension | 新适应症拓展 |
| 药企合作 | 外部对照臂提供 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 数据处理 | Python (pandas), SAS, SQL |
| 因果推断 | causallib, dowhy, lifelines |
| NLP/LLM | spaCy, transformers, ChatGPT API |
| 深度学习 | PyTorch, TensorFlow, BERT |
| 可视化 | matplotlib, plotly, SHAP |
| 报告生成 | markdown, docx, LaTeX |
