## 各层详细说明

### 1. 真实世界数据层 (RWD)

| 数据源 | 说明 |
|--------|------|
| EMR | 电子病历系统 |
| Lab | 实验室检验数据 |
| Imaging | 影像数据 (CT/MRI/PET) |
| Pharmacy | 处方/用药数据 |
| Registry | 患者登记数据 |

---

### 2. 数据处理与标准化层

| 模块 | 功能 |
|------|------|
| 数据清洗 | 缺失值处理、异常值检测 |
| 变量构建 | 倾向评分、协变量构建 |
| NLP | 从非结构化文本抽取临床变量 |

---

### 3. 因果分析核心层

| 方法 | 用途 |
|------|------|
| Target Trial Emulation | 模拟RCT的观察性研究设计 |
| IPTW | 逆概率处理加权 |
| PS模型 | 倾向评分估计 |
| Time-dependent Cox | 时间依赖Cox回归 (irAE分析) |
| 敏感性分析 | 未测混杂、残留混杂评估 |

---

### 4. 功能模块层

| 模块 | 子功能 |
|------|--------|
| **疗效模块** | PD-1 vs 非PD-1, OS/PFS/ORR |
| **安全性模块** | irAE发生率, 时间依赖分析 |
| **分层模块** | ECOG/LDH/线别/ refractory |
| **治疗策略** | 早用vs晚用, 联合vs序贯 |
| **AI模块** | NLP抽取, 风险预测, 报告生成 |

---

### 5. 证据输出层

| 输出 | 说明 |
|------|------|
| HR / 95%CI | 风险比及置信区间 |
| KM曲线 | Kaplan-Meier生存曲线 |
| Cox结果 | 多因素回归结果 |
| Love Plot | 加权前后协变量平衡图 |
| SMD | 标准化均值差 |
| ESS | 有效样本量 |
| 自动报告 | 结构化JSON/Word报告 |

---

### 6. 应用与转化层

| 应用场景 | 价值 |
|----------|------|
| 临床决策支持 | 精准治疗推荐 |
| 学术发表 | 高质量RWE论文 |
| External Control Arm | 单臂研究对照 |
| 注册申报 | NMPA/FDA补充证据 |

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 数据处理 | Python (pandas), SAS |
| 因果推断 | causallib, dowhy, lifelines |
| NLP | spaCy, transformers |
| 可视化 | matplotlib, plotly |
| 报告生成 | markdown, docx |

---

## 数据流向

```
RWD → 标准化 → 因果分析 → 功能模块 → 证据输出 → 临床/学术/注册
```
