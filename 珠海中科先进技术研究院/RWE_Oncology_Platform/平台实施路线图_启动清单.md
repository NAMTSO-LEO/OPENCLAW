## 二、最小可用数据集 (必备字段)

### 2.1 基线信息

| 变量 | 说明 |
|------|------|
| patient_id | 患者ID |
| age | 年龄 |
| sex | 性别 |
| diagnosis_date | 诊断日期 |
| stage | 分期 |
| pathology | 病理分型 |
| ECOG | ECOG评分 |
| comorbidity | 合并症 |
| prior_lines | 既往治疗线数 |

### 2.2 治疗信息

| 变量 | 说明 |
|------|------|
| treatment_start | 治疗开始时间 |
| treatment regimen | 治疗方案 |
| pd1_flag | 是否PD-1 (1/0) |
| combination | 联合治疗情况 |
| treatment_end | 停药时间 |
| line_switch | 换线时间 |

### 2.3 结局信息

| 变量 | 说明 |
|------|------|
| OS | 总生存期 |
| PFS | 无进展生存期 |
| ORR/DCR | 缓解情况 |
| last_followup | 末次随访时间 |
| death_date | 死亡时间 |

### 2.4 安全性信息

| 变量 | 说明 |
|------|------|
| irAE_flag | irAE是否发生 (1/0) |
| irAE_onset | irAE发生时间 |
| irAE_type | irAE类型 |
| irAE_grade | irAE分级 |
| irAE_management | 处理措施 |

### 2.5 实验室/疾病状态

| 变量 | 说明 |
|------|------|
| LDH | 乳酸脱氢酶 |
| CBC | 血常规 |
| liver_renal | 肝肾功能 |
| inflammation | 炎症指标 |
| tumor_burden | 肿瘤负荷相关变量 |

## 四、方法学组合 (第一版够用)

### 4.1 疗效分析

| 方法 | 用途 |
|------|------|
| Kaplan-Meier | 生存曲线 |
| Cox | 单因素/多因素 |
| Propensity Score | 倾向评分 |
| IPTW | 逆概率加权 |
| Target Trial Emulation | RCT模拟设计 |

### 4.2 安全性分析

| 方法 | 用途 |
|------|------|
| start-stop格式 | 时间依赖数据结构 |
| time-dependent Cox | irAE时间依赖分析 |

### 4.3 诊断检查

| 方法 | 用途 |
|------|------|
| SMD | 标准化均值差 |
| Love Plot | 协变量平衡可视化 |
| ESS | 有效样本量 |
| overlap检查 | PS分布重叠 |
| 权重分布 | IPTW权重分布 |
| 敏感性分析 | 未测混杂评估 |

## 十、最容易踩的坑 (警示)

| 坑 | 说明 |
|----|------|
| ❌ 做得太大 | 同时做多病种/多中心/大模型 |
| ❌ AI先行 | 不是"我能用什么模型"，是"我要解决什么证据问题" |
| ❌ 数据定义不严 | 变量口径不统一 |
| ❌ 只看预测 | 价值在"可信证据"，不是预测分数 |

---

## 十一、判断标准 (5个问题)

在开始前确认这5个问题都能回答"是"：

- [ ] 研究问题是否能一句话说清
- [ ] time zero是否定义清楚
- [ ] 最小数据集是否列全
- [ ] pipeline是否能在模拟数据上跑通
- [ ] 第一版输出是否能做成一套完整汇报
