# 垂体瘤综合治疗方案项目

本项目用于整理“垂体瘤综合治疗方案：结合 Gamma Knife（伽玛刀）+ 分子靶点 + 临床治疗优化”的科研材料。

## 建议使用方式
- `01_研究方案`：放开题、研究设计、研究目标、纳排标准
- `02_文献整理`：放文献阅读笔记、综述提纲、检索策略
- `03_临床资料与数据`：放病例信息模板、变量字典、随访表
- `04_分子靶点`：放靶点机制、标志物整理、检测思路
- `05_Gamma刀方案`：放放疗适应证、剂量思路、病例分层
- `06_统计分析`：放统计方案、终点设定、分析脚本说明
- `07_图表与流程图`：放研究流程图、技术路线图、结果图表
- `08_PPT与汇报`：放答辩稿、汇报提纲、会议PPT
- `09_初稿与终稿`：放综述、课题申请书、论文草稿
- `10_参考文献`：放参考文献清单和引用格式文件

你可以把这个文件夹当成整个课题的总目录。
