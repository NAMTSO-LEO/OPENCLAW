# AI 建模变量字典

## 一、结局变量（Y）

### 主要结局
1. **局部控制失败**
   - 定义：Gamma Knife 或综合治疗后影像提示肿瘤进展 / 明显增大
   - 类型：二分类 / 时间到事件

2. **复发**
   - 定义：术后或治疗后稳定期再次出现影像学进展或激素异常提示复发
   - 类型：二分类 / 时间到事件

3. **激素未缓解**
   - 定义：随访期内相关激素未达到预设生化缓解标准
   - 类型：二分类

### 次要结局
4. 视功能恶化
5. 垂体功能减退
6. 再手术
7. 无进展生存期（PFS）

## 二、临床变量（X-clinical）
- 年龄
- 性别
- 肿瘤亚型（PRL/GH/ACTH/NFPA/侵袭性）
- 功能性/无功能性
- 首次治疗方式
- 是否术后残留
- 是否复发后入组
- 基线激素水平（PRL/GH/IGF-1/ACTH/Cortisol/TSH）
- 药物治疗种类
- 随访时长

## 三、影像变量（X-imaging）
### 常规影像
- 肿瘤最大径
- 肿瘤体积
- Knosp 分级
- 海绵窦侵犯
- 鞍上扩展
- 视交叉受压
- 肿瘤边界清晰度
- 强化方式

### 影像组学
- 一阶统计量
- 纹理特征
- 形状特征
- 小波特征
- 灰度共生矩阵相关特征

## 四、Gamma Knife 变量（X-GK）
- 是否接受 Gamma Knife
- Gamma Knife 时间点（术后早期 / 复发后 / 其他）
- 靶区体积
- 处方剂量
- 边缘剂量
- 最大剂量
- 视路受量
- 靶区覆盖率
- 与危险结构距离

## 五、病理与分子变量（X-molecular）
- Ki-67
- p53
- MGMT
- SSTR2
- SSTR5
- D2 receptor
- USP8
- AIP
- GNAS
- EGFR
- VEGF
- PI3K/AKT/mTOR 通路相关指标
- 其他可获得的 IHC / 基因突变变量

## 六、特征工程建议
- 连续变量标准化
- 分类变量独热编码
- 缺失值多重插补或合理填补
- 共线性检测
- 极端值处理
- 时间变量统一单位（月）

## 七、建模建议
### 基线模型
- Logistic regression
- Cox regression

### 机器学习模型
- LASSO
- Elastic Net
- Random Forest
- XGBoost
- LightGBM

### 评估指标
- AUC
- C-index
- 灵敏度/特异度
- F1 score
- 校准曲线
- DCA
- SHAP

## 八、输出目标
- 高风险患者识别
- Gamma Knife 获益人群识别
- 复发风险分层
- 临床决策支持工具（评分系统 / nomogram）
