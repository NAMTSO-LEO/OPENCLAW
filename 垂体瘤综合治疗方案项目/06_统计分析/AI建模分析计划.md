# AI 建模分析计划

## 一、分析目标
构建并验证垂体瘤多模态预测模型，识别与复发、局部控制失败和激素未缓解相关的关键分子靶点及影像特征。

## 二、分析流程
1. 数据清洗与缺失值评估
2. 变量标准化与编码
3. 训练集 / 验证集 / 外部测试集划分
4. 单因素分析
5. 特征选择（LASSO / RF / XGBoost / RFE）
6. 建立临床模型、分子模型、影像模型、融合模型
7. 性能评估与比较
8. SHAP 可解释性分析
9. 校准曲线与 DCA
10. 亚组分析与敏感性分析

## 三、数据划分建议
- 如果样本量充足：70% 训练 / 15% 验证 / 15% 测试
- 如果样本量一般：按时间分割，例如 2020–2024 训练，2025–2026 验证
- 若有多中心：外部中心单独验证

## 四、模型比较框架
- Model 1：临床变量模型
- Model 2：分子变量模型
- Model 3：影像 / Gamma Knife 模型
- Model 4：临床 + 分子融合模型
- Model 5：临床 + 影像融合模型
- Model 6：临床 + 分子 + 影像全融合模型

## 五、敏感性分析
- 不同肿瘤亚型分层
- 功能性 vs 无功能性
- 是否术后残留
- 是否接受 Gamma Knife
- 不同随访时长阈值

## 六、最终输出
- 主模型 ROC / C-index
- 校准曲线
- DCA 曲线
- SHAP 图
- 风险分层图
- nomogram 或在线评分原型
