## 二、内容形式

### 形式1: 连续短剧 (推荐)

**每集时长**: 1-3分钟
**集数**: 20-30集
**更新频率**: 1-2集/天

**结构**:
```
第1集: 十年危机爆发 (承接小说第一章)
第2-5集: 回忆杀 (大学初遇)
第6-10集: 矛盾升级
第11-15集: 分开冷静
第16-20集: 追夫火葬场
第21-25集: 重新追求
第26-30集: 大结局
```

### 形式2: 精华片段

**时长**: 30-60秒
**内容**: 名场面合集
**更新频率**: 1个/天

## 三、制作流程

### Step 1: 剧本改编

把小说拆成1-3分钟/集的短剧

**模板**:
```
【场景1】时间地点
【对话】主要对白
【情绪】哭/笑/吻
【悬念】结尾悬念
```

### Step 2: 拍摄准备

**设备**:
| 设备 | 推荐 | 预算 |
|------|------|------|
| 手机 | iPhone 14+ | 6000+ |
| 稳定器 | 大疆OM6 | 800 |
| 补光灯 | LED环形灯 | 200 |
| 收音 | 无线麦克风 | 300 |

**演员**: 自己演 or 找朋友客串

### Step 3: 剪辑

**工具**:
| 工具 | 难度 | 费用 |
|------|------|------|
| 剪映 | 简单 | 免费 |
| CapCut | 简单 | 免费 |
| Premiere | 专业 | ¥800/月 |

**剪辑节奏**:
```
0-5秒: 抓眼球 (冲突/吻戏)
5-30秒: 核心内容
30-60秒: 情绪高潮
结尾: 悬念/引导关注
```

### Step 4: 发布

**平台**:
| 平台 | 时长 | 特点 |
|------|------|------|
| 抖音 | 15-60秒 | 流量大 |
| 快手 | 30秒-3分钟 | 接地气 |
| 小红书 | 1-3分钟 | 女性多 |
| B站 | 3-10分钟 | 深度 |

## 四、第1集示例

### 剧本: 十年危机

**时长**: 2分钟

**画面1** (0-15秒)
```
场景: 餐厅 晚上
[两人对坐，烛光晚餐]
[林]平静: "明远，我们分手吧。"
[沈]震惊: "什么？"
```

**画面2** (15-45秒)
```
[林]低头: "十年了，我觉得好累。"
[沈]握拳: "是因为那个男人？"
[林]苦笑: "原来你知道了。"
```

**画面3** (45-90秒)
```
[沈]站起，拿照片: "你还记得这天吗？"
[照片: 大学操场两人的合影]
[沈]深情: "2004年，我们第一次见面。"
[林]眼眶红: "记得......"
```

**画面4** (90-120秒)
```
[沈]恳求: "给我三个月。"
[林]犹豫......点头
[旁白]: "十年感情，能否挽回？"
[结尾悬念]
```
