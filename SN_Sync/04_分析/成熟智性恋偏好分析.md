# 成熟智性恋偏好分析

## 一、核心特征

这种类型的伴侣兴趣结构是**"审美型亲密"**，而非性刺激。

| 特征 | 说明 |
|------|------|
| 成熟 | 年龄、经验、稳重 |
| 智性恋 | 被智慧、思考能力吸引 |
| 日本元素 | 文化氛围、克制美学 |
| 低性欲 | 不追求性行为本身 |
