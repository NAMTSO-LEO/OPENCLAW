# 生长激素腺瘤伽玛刀治疗研究计划

## 一、研究背景

### 1.1 疾病概述
- 生长激素腺瘤（Growth Hormone-secreting pituitary adenoma）
- 导致肢端肥大症（Acromegaly）或巨人症
- 首选治疗：经鼻蝶手术
- 仍有部分患者术后残留/复发，需要二线治疗

### 1.2 伽玛刀治疗价值
- 作为手术失败后的重要补充治疗
- 适用于：术后残留、复发、不适合再次手术
- 优势：微创、精准、并发症相对较低

### 1.3 研究空白
- 现有研究多为小样本回顾性分析
- 缺乏结合临床、影像、分子特征的预后模型
- AI/ML 在此领域应用潜力大

---

## 二、研究目的

### 2.1 主要目的
评估伽玛刀治疗生长激素腺瘤的有效性和安全性，建立预后预测模型。

### 2.2 次要目的
- 分析与 IGF-1 生化缓解相关的因素
- 分析与肿瘤控制相关的因素
- 建立基于临床和影像特征的 AI 预后模型
- 识别潜在预后生物标志物

---

## 三、研究设计

### 3.1 研究类型
- 回顾性队列研究
- 单中心或双中心

### 3.2 研究人群

#### 纳入标准
- 明确诊断为生长激素腺瘤（病理/影像+激素）
- 接受伽玛刀治疗
- 有术后随访数据（≥6个月）

#### 排除标准
- 既往放疗史
- 失访
- 数据严重缺失

### 3.3 治疗指征
- 术后残留/复发
- 不适合/不愿再次手术
- 药物治疗效果不佳/不耐受

---

## 四、数据收集清单

### 4.1 人口学资料
| 变量 | 说明 |
|------|------|
| 年龄 | 诊断/治疗时年龄 |
| 性别 | 男/女 |
| 病程 | 症状出现至治疗时间 |
| 既往手术次数 | 伽玛刀前手术次数 |

### 4.2 肿瘤特征
| 变量 | 说明 |
|------|------|
| 肿瘤最大径 | mm |
| 肿瘤体积 | mm³ |
| Knosp分级 | 0-4 |
| 海绵窦侵袭 | 是/否 |
| 鞍上扩展 | 是/否 |
| 侵袭性指标 | 影像学特征 |

### 4.3 激素指标（关键）
| 变量 | 基线 | 随访 |
|------|------|------|
| GH | ✓ | ✓ |
| IGF-1 | ✓ | ✓ |
| IGF-1正常化 | - | ✓ |

### 4.4 伽玛刀参数
| 变量 | 说明 |
|------|------|
| 处方剂量 | Gy |
| 边缘剂量 | Gy |
| 最大剂量 | Gy |
| 靶区体积 | mm³ |
| 靶区数 | 个 |
| 治疗日期 | - |

### 4.5 治疗史
| 变量 | 说明 |
|------|------|
| 术前药物治疗 | 是/否，药物类型 |
| 手术方式 | 内镜/显微镜 |
| 术后残留 | 是/否 |
| 既往放疗 | 是/否 |

### 4.6 随访资料
| 变量 | 说明 |
|------|------|
| 随访时间 | 月 |
| IGF-1变化 | 数值+正常化时间 |
| 肿瘤控制 | 缩小/稳定/增大 |
| 复发 | 是/否 |
| 并发症 | 视力/垂体功能/其他 |

---

## 五、结局定义

### 5.1 主要结局
- **生化缓解**：IGF-1 正常化（按年龄校正标准）
- **肿瘤控制**：肿瘤体积缩小或稳定

### 5.2 次要结局
- 无进展生存期（PFS）
- 总生存期（OS）
- 并发症发生率
- 垂体功能变化

---

## 六、AI/ML 预后模型设计

### 6.1 预测目标
- 伽玛刀后 IGF-1 是否正常化
- 肿瘤是否得到控制
- 是否复发

### 6.2 特征变量
| 类别 | 变量 |
|------|------|
| 临床 | 年龄、性别、病程、既往治疗 |
| 影像 | 肿瘤体积、位置、侵袭性、信号特征 |
| 激素 | 基线GH、基线IGF-1 |
| 放疗 | 剂量、体积、靶区数 |

### 6.3 建模方法
| 方法 | 用途 |
|------|------|
| Logistic Regression | 基线模型 |
| Random Forest | 特征重要性 |
| XGBoost | 预测性能 |
| SHAP | 可解释性分析 |

### 6.4 验证策略
- 内部验证（时间分割/交叉验证）
- 外部验证（如有条件）

---

## 七、统计方法

### 7.1 描述性分析
- 均值、中位数、频数

### 7.2 单因素分析
- t检验/卡方检验
- Kaplan-Meier + Log-rank

### 7.3 多因素分析
- Cox 回归
- Logistic 回归

### 7.4 机器学习
- 特征选择
- 模型构建
- 性能评估（AUC、灵敏度、特异度）
